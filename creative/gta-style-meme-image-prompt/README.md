# gta-style-meme-image-prompt

写 ChatGPT（GPT-4o/DALL·E）生图提示词，复刻「PS2 时代 GTA 圣安地列斯游戏截图 + 荒诞场景」的网络梗图风格（小红书流传的 CJ 快餐店/玩具车系列那类图）。

## 解决的问题

- 看得出梗图好笑、说不清好笑在哪 → 拆解出四要素配方：低多边形渲染基调、CJ 式主角（白背心牛仔裤）、荒诞错位场景、夸张表情
- 生成的图没梗味 → 提示词模板把四要素固定成槽位，换主题只填场景/动作/道具/标题
- 图上中文字乱码错字 → 「文字必须精确为：×××」限定 + 生成后回读检查话术

## 文件结构

| 文件 | 用途 |
|---|---|
| `SKILL.md` | 风格拆解、中文提示词模板、实战坑位、参考图分析流程 |

## 核心流程

1. `vision_analyze` 拆参考图：画风基调（低多边形截图 vs 官方插画海报）、主角特征、场景、文字排版
2. 套四要素模板，填入用户主题的四个槽位
3. 交付提示词 + 中文字精确检查提醒

细节和坑位全在 [SKILL.md](creative/gta-style-meme-image-prompt/SKILL.md)。

## 实战坑位摘要

- 图上中文标题必须原样写进提示词并加「文字必须精确为」限定，错了就回「文字改成精确的：×××，其他不变」
- 「夸张表情（瞪大眼、张大嘴）」不可省略，少了出图面无表情、梗味全无
- 低多边形关键词要全图统一：写实人物 + 游戏环境是可取反差，游戏人物 + 照片级环境是失控
- 比例写「游戏截图比例」（4:3/16:9），竖屏会破坏截图感
- 参考图来自小红书截图时，剥离平台水印（AI 角标、图集页码），别写进提示词

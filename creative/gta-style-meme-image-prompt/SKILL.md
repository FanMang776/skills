# GTA 风格游戏梗图提示词

## When to Use

- 用户发来 GTA 老游戏截图风梗图（低多边形 CJ + 荒诞场景），要求仿写/生成类似图。
- 用户要给 ChatGPT/GPT-4o 生图写「游戏截图风 + 中文标题」的提示词。
- 不适用：官方 GTA 海报仿制（那是 Stephen Bliss 插画风，不是本技能的低多边形截图风）。

为 ChatGPT（GPT-4o/DALL·E）生图写提示词，复刻「PS2 时代 GTA 圣安地列斯游戏截图 + 写实 AI 人物混搭」的网络梗图风格。参考样本：小红书上流传的 CJ 在快餐店/Cozy Coupe 玩具车系列梗图。

## 风格拆解（先看懂参考图再动笔）

这种梗图的视觉配方有四个固定要素，提示词必须逐一覆盖：

1. **低多边形渲染基调**：整张图是 2004 年 PS2 游戏截图质感——人物棱角分明、贴图略糊、阴影边缘生硬硬、暖黄微尘霾滤镜（圣安地列斯加州色调）。
2. **CJ 式主角**：照 GTA 圣安地列斯主角 CJ 设计的黑人男性，白工字背心 + 蓝色牛仔裤，保持低多边形游戏建模风格。
3. **荒诞错位场景**：一个离谱的现代事物/行为出现在游戏世界里（玩具车开上大街、真人坐快餐店、玩 Switch 把家里搞成灾难现场），这是笑点本体。
4. **夸张表情**：瞪大眼、张大嘴、身体前倾——CJ 梗图的灵魂，提示词里必须显式写出，不可省略。

## 提示词模板（中文，直接粘贴进 ChatGPT）

```
生成一张模仿 PS2 时代《GTA：圣安地列斯》游戏截图风格的梗图。
场景：<一句话描述地点和氛围，如：一间略显拥挤杂乱的年轻人客厅，暖黄色室内光>。
整体画面保持 2004 年 PS2 游戏的低多边形渲染质感——人物棱角分明、贴图略糊、阴影生硬。

主角：照 GTA 圣安地列斯 CJ 造型设计的黑人男性，白色工字背心 + 蓝色牛仔裤，
低多边形游戏建模风格，<动作姿势，如：盘腿坐在沙发上>，
表情夸张（瞪大眼、张大嘴、身体前倾），<正在做什么，如：双手握着 Nintendo Switch 玩胡闹厨房>。

场景细节：2-3 个荒诞喜剧道具（如：地上薯片袋可乐罐、茶几上冒烟的锅），
制造「<一句话概括笑点>」的荒诞感。

画面上方居中一行大字标题：「<标题文字>」，使用 GTA 系列标志性的
Pricedown 风格粗体字体（白色带黑色描边），类似游戏 logo 排版。

整体氛围：怀旧、荒诞、好笑的游戏梗图，游戏截图比例。
```

英文版画风还原通常更稳，中文版对中文标题文字更稳；用户没指定时优先中文版（标题是中文的，两边都用中文写可减少模型切换语言时的错字）。

## 坑

- **图上中文字必须原样写进提示词并加「文字必须精确为：×××」**，否则 GPT-4o 会错字漏字。生成后回读检查文字；错了就回一句「文字改成精确的：×××，其他不变」重新生成。
- **「夸张表情」四个字别删**——少了它出图人物面无表情，梗味全无。
- 低多边形关键词必须全图统一。若出图一半写实一半游戏（写实人物 + 游戏环境是可取的反差；游戏人物 + 照片级环境是失控），在提示词里补「主角保持低多边形游戏建模风格」。
- 比例要求写「游戏截图比例」（4:3 或 16:9），写竖屏会破坏截图感。
- 参考图若来自小红书截图，注意剥离平台水印（「可能含AI生成内容」角标、图集页码），不要把这些写进提示词。

## 流程

1. 用户发参考图时，先用 `vision_analyze` 拆解：画风基调（低多边形/插画/写实）、主角特征、场景、文字排版、色调，识别出「这是游戏截图梗图而非官方海报」。
2. 按上面四要素套模板，把用户的主题填进场景、动作、道具、标题四个槽位。
3. 交付中英文两版提示词 + 文字检查提醒。

## 验证

- 提示词包含全部四要素关键词（低多边形、CJ 背心造型、夸张表情、荒诞道具）。
- 标题文字在提示词中原样出现且有「精确为」限定。
- 用户实际生成的图：文字无错字、主角保持游戏质感即算成功。

# three-question-domain-ramp（三问速通陌生领域）

用 AI 做**出题人和判卷人**（而不是代笔）在数小时~数天内吃透一个陌生领域的可复用流程。
源自 X 走红的 MIT 研究生案例（抖音账号"学习有了方法"中文转述）：
**20 分钟建知识版图 + 48 小时演练循环**。

## 核心思想

普通人用 AI 学习的误区是让 AI 总结笔记、罗列要点——那是让 AI 替你完成认知加工，
"大脑退化成旁观者"。本方法反其道而行：AI 负责搭建地图和出题施压，**你**负责答题，
答错就追问"错在哪里、漏了什么"。

三个问题层层递进：

1. **Q1 领域共识** — "所有专家共用的五个核心思维模型是什么？"（要框架，不要摘要）
2. **Q2 领域分歧** — "专家根本分歧的三个争议点及各方最强论据？"（共识给结构，分歧给边界）
3. **Q3 出题自测** — "出 10 道深测题考我"（费曼式的输出检验）

## 使用

1. 触发：对 agent 说"帮我速通 X 领域"
2. 按 [`SKILL.md`](SKILL.md) 的 6 步流程执行；产出物套用 `templates/` 下两个模板：
   - [`templates/knowledge-map.md`](templates/knowledge-map.md) — 知识版图（五框架 + 争议地图 + 术语表 + 盲区清单）
   - [`templates/quiz.md`](templates/quiz.md) — 试题 + 覆盖映射 + 演练记录
3. 通过标准：一轮 10/10 逐条核对判分标准 + 错题混合新题的重测轮通过 +
   不看文档能复述至少三个框架

## 关键纪律（为什么大多数人不这样做）

- **判卷人不能替考生答题** —— 时间再紧也不代答，代答 = 全流程作废
- **所有结论必须标语料出处** —— 无出处不进版图，防线只有一个：基于语料
- **不硬凑争议** —— 假分歧比没有分歧更误导
- **语料宁缺勿滥** —— 垃圾语料会污染后续所有问答
